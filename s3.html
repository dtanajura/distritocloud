O que é o Amazon S3?

Armazenamento de Objetos

Diferente de blocos (HDs). Armazena arquivos como Chave (Caminho/Nome) e Valor (Dados binários).

Escalabilidade Infinita

Não há limite de espaço total. Armazene de bytes a **Petabytes** sem precisar provisionar storage antes.

Resiliência Absoluta

Projetado para **99.999999999% (11 noves) de durabilidade**. Seus dados são replicados em no mínimo 3 AZs.

Recursos de Segurança e Controle

Versionamento & Object Lock

O Versioning protege contra exclusões acidentais mantendo o histórico de alterações. O Object Lock impede a deleção e modificação de arquivos (modelo WORM - contra Ransomware).

Controle de Acesso

Por padrão, tudo no S3 é **100% privado**. O acesso é controlado via **Bucket Policies** (Políticas JSON anexadas ao bucket) e regras de **Block Public Access** global.

Laboratório Prático

Mão na massa: Hospedando um site estático seguro no Amazon S3

Prática

Objetivos do Laboratório

  • Criar um Bucket S3 com nomenclatura global exclusiva.
  • Realizar o Upload de arquivos do site (`index.html`).
  • Gerenciar as permissões e desativar o bloqueio público.
  • Ativar o recurso **Static Website Hosting** e testar a URL final.
Prática

Roteiro de Execução do Lab

  • No console do S3, clique em "Create bucket". Use letras minúsculas e hífens.
  • Desmarque a opção "Block Public Access" (necessário apenas para sites públicos).
  • Dentro do bucket, faça upload de um arquivo chamado index.html.
  • Vá em Properties, role até o final e ative o Static website hosting.
  • Vá em Permissions -> Bucket Policy e cole a política JSON liberando a ação s3:GetObject para o principal público ("*").
  • Copie o Endpoint gerado nas propriedades e abra no navegador!
